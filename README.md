# 河北大学校友地图小程序

这是一个原生微信小程序 MVP，包含校友之家地图标点、搜索筛选、详情页、地图导航、电话联系、微信号/地址复制和图片预览。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”，项目目录选择 `hbu-alumni-map`。
3. 没有正式 AppID 时可使用测试号或游客模式；上线前把 `project.config.json` 中的 `appid` 改成真实 AppID。
4. 编译后首页会展示地图和示例校友之家点位。

## 替换真实数据

校友之家数据集中在 `data/homes.js`。上线前请替换：

- `name`：校友之家名称。
- `latitude` / `longitude`：腾讯地图或高德地图的 GCJ-02 坐标。
- `address`：可导航的真实地址。
- `phone` / `wechat` / `contactName`：联系方式。
- `services`：服务标签，例如活动报名、就业内推、会议空间。
- `photos`：本地图片路径，建议放在 `assets/photos`。

当前点位、电话、地址均为示例数据，不能直接作为真实导航信息发布。

## 页面结构

- `pages/index`：地图首页，支持定位、路况、搜索、服务筛选、列表导航。
- `pages/detail`：校友之家详情，支持图片轮播、地图导航、拨打电话、复制微信和地址。
- `data/homes.js`：校友之家数据源。
